# GW170817 HyperWave pilot

## Student tutorial

The English notebook now includes an AT2017gfo light-curve section: pinned
observational photometry in optical/NIR filters, time alignment to the GW GPS
epoch, explicit upper limits and fast weighted decline fits. It now also executes joint GW–EM inference with shared distance and merger time.
The descriptive fits do not constrain ejecta, EOS, distance or inclination.

```sh
.venv/bin/python examples/real_event/at2017gfo_lightcurve.py
.venv/bin/python examples/real_event/gw170817_tutorial.py --mode fast --sample --lightcurve
```

Light-curve inputs are bundled in `at2017gfo_data/` with checksum and source
attribution; no extra download or NMMA installation is needed. In notebook
preview mode, the GW results are saved results, while this short EM analysis
can still run on the bundled observations. Set `RUN_LIGHTCURVE=False` to skip it.

Open `GW170817_tutorial.ipynb` for the English teaching notebook with equations,
PSD and likelihood plots, targeted recovery, conditional Eryn sampling,
chain diagnostics, exercises, and opt-in full PE cells. The notebook defaults
to a live fast run; `MODE='preview'` displays bundled previous fast outputs
without downloading strain. Full sampling is disabled in Run All.

```sh
.venv/bin/python -m pip install jupyterlab ipykernel
.venv/bin/python -m ipykernel install --user --name hyperwave-tutorial --display-name 'HyperWave tutorial'
.venv/bin/jupyter lab examples/real_event/GW170817_tutorial.ipynb
.venv/bin/python examples/real_event/gw170817_tutorial.py --mode fast --sample
.venv/bin/python examples/real_event/gw170817_tutorial.py --mode preview
.venv/bin/python examples/real_event/gw170817_tutorial.py --mode full
```

Select the **HyperWave tutorial** kernel. The live fast profile uses 32 s,
2048 Hz sampling and 64–512 Hz, with 10 burn-in and 20 production steps by
default. It shares the pinned 4096 Hz input file cache with the larger analysis
and resamples the chosen segments. The first download is approximately
175 MiB; cached sampling took a few seconds locally. This reduced band gives
a targeted quadrature SNR around 27, versus around 34 for the earlier wider-band
pilot. These profiles do not have equivalent information or posteriors.
The completed notebook was tested with cached inputs: live fast Run All took
about 53 seconds including the new joint sampler; preview took about 4 seconds.
Actual times vary. The delivered notebook includes outputs from the executed fast path.

For long sampling add `--mode full --sample`, optionally `--steps` and `--burn`.
Use separate output directories for independent runs and likelihood choices.
Hours or longer may be needed; convergence is not guaranteed by the defaults.

This pilot recovers GW170817 in real, cleaned H1/L1/V1 strain and provides a
short **conditional** parameter estimation diagnostic. It does not reproduce
the discovery false-alarm rate or the published multidimensional PE posterior.

## Executable joint GW–EM PE

The notebook now includes an 8-parameter joint Eryn run: four conditional GW
parameters and four expanding/cooling blackbody photosphere parameters, with
shared luminosity distance and merger epoch. The EM likelihood uses 33 actual
grizy detections at 0.4–2.5 observer-frame days,
band-integrated AB fluxes, fixed z=0.0098, foreground E(B-V)=0.105 with F99
Rv=3.1, and an illustrative independent 0.20 mag model-error floor.

Six scientific checks pass, including an independent wavelength-domain AB
flux integral, shared-likelihood composition and distance/radius scaling.
Both fast and preview notebook Run All passed; the 21-parameter full setup
passed a finite-likelihood check. Long-chain convergence has not been tested.

The joint section runs by default in fast mode (`RUN_JOINT_PE=True`), with
10 burn-in + 40 production steps, 24 walkers and two temperatures. Preview
skips joint sampling. Plots include the joint corner, EM model draws/residuals,
walker traces and a short-chain GW-only/joint distance comparison. The exact
radius–distance scaling degeneracy is checked in a cell: this EM model does
not independently constrain distance or inclination. It measures a photospheric
scale using the GW distance, conditional on the model and priors.

```sh
.venv/bin/python examples/real_event/gw170817_tutorial.py --mode fast --joint --sample
# Same standalone implementation, configurable chain length:
.venv/bin/python examples/real_event/gw170817_joint.py --mode fast --sample --burn 10 --steps 40
# Full 17 GW + 4 EM parameters: setup only unless --sample is supplied:
.venv/bin/python examples/real_event/gw170817_joint.py --mode full
.venv/bin/python examples/real_event/gw170817_joint.py --mode full --sample --burn 1000 --steps 1000 --outdir results/joint_full_01
```

The full joint path is disabled in notebook Run All (`RUN_FULL_JOINT_PE=False`).
It uses 64 walkers, four temperatures and the full GW driver's volume-distance
prior; hours or longer may be needed. It retains the same approximate EM model.
Neither path establishes convergence by step count. Neither infers ejecta mass,
opacity or EOS, nor includes an EM viewing-angle model. Association is assumed;
no additional host-position or selection likelihood is included. Gaussian GW
noise is currently the supported joint option.

Photometry and filter checksums, priors, EM cuts, assumed dust/redshift/scatter,
seed and sampler settings are saved in `joint_manifest.json`; GW data choices
are saved in `gw_manifest.json`. Selected data, chains, samples, quantiles and
plots accompany them. Reusing an output directory replaces that run's chain.
The filter throughput and F99 attenuation tables are bundled; ordinary use
requires no SNCosmo, dust_extinction or NMMA installation. Treat compiled
filter labels, foreground correction and independent errors as assumptions,
and test their sensitivity before drawing astrophysical conclusions.

After a successful setup/fit, add `--reuse-fit` to skip recovery and optimization
when repeating sampling; the script checks the analysis settings and data
checksums before reusing the fit. Eryn 1.2.6 requires NumPy <2.4 because it uses
the removed `np.in1d` API. A local Matplotlib compatibility import fix is also
included in this checkout.

The first execution downloads three 2048 s, 4096 Hz HDF5 files. Subsequent runs
reuse the cache. All outputs are under `results/gw170817`; use a separate
`--outdir` for each experiment because the Eryn driver replaces its chain file.
The manifest records the exact data URLs, local SHA256 checksums, repository
commit, dependencies, frequency band, data cuts and fixed parameters.

## Initial verification on real strain

The first targeted recovery gave quadrature SNR **33.98**, with the best chirp
mass grid point at **1.1975 solar masses in the detector frame**. Conditional
Gaussian optimization converged at chirp mass 1.197482 solar masses and increased
log likelihood by 529.56 over the zero-signal model. This likelihood gain is not
a Bayes factor or a false-alarm probability.

Two BNS waveform regression tests pass: TaylorF2 and IMRPhenomPv2_NRTidal
agree exactly with the Bilby/LAL neutron-star source, and nonzero tides change
the waveforms. A separate analytic correlation check confirms the SNR
normalization and time-lag sign. Real-data checks confirm consistent Gaussian
batch/single evaluation, finite hyperbolic likelihood, and unchanged data.
The 17-parameter Gaussian and 22-parameter hyperbolic configurations both pass
their setup checks. These checks do not establish posterior convergence.
The conditional Gaussian Eryn pilot completed 50 burn-in and 100 production
steps with 24 walkers and two temperatures, saving 2400 cold-chain draws.
These correlated draws are not an effective sample count. Its diagnostic
chirp-mass median was 1.197490 solar masses; the full posteriors remain unrun.

## Analysis choices

- Explicit `O1_O2-Preliminary/GW170817/v2` cleaned release, not generic open-data
  fetching: the latter can return a release containing the Livingston glitch.
- 256 s analysis segment with two seconds after the rounded event time;
  23–1024 Hz, 4096 Hz sampling. This is a practical initial band, not the full
  tidal-information band or an exact published analysis setup.
- Median Welch PSD: 16 s Hann windows, 50% overlap, 512 s of off-source strain
  ending 32 s before the analysis segment. This avoids the inspiral and the
  corrupted final portion of the cleaned Hanford file.
- LAL TaylorF2 with nonzero tidal deformabilities. Chirp mass is detector-frame.
- Targeted recovery: scan 31 chirp masses near the known event and compute
  phase-maximized per-detector correlations. The quadrature sum is an
  **incoherent targeted recovery statistic**, not a coherent search statistic,
  a background-calibrated significance, or the published network SNR.
- Conditional PE samples chirp mass, distance, phase and coalescence time.
  Mass ratio, host sky position, orientation, polarization, spins and tides
  remain fixed and are listed in the manifest. Distance and mass intervals
  depend on these restrictions and must not be interpreted as LVK posteriors.
- A short two-temperature Eryn chain verifies the pipeline. Quantiles and
  corner plots are diagnostic; convergence is not established by step count.

## Moving to a scientific reproduction

`gw170817_pe.py` provides the larger 17-parameter configuration (including
precessing low spins, unrestricted sky position and both tidal deformabilities).
It defaults to `IMRPhenomPv2_NRTidal`, uniform detector-frame chirp mass and mass
ratio, isotropic spin directions and sky, spin magnitudes in [0, 0.05], a
Euclidean volume distance prior in [5, 100] Mpc, and independent uniform tides
in [0, 5000]. These are explicit reanalysis choices, not a claim to match the
published priors. Its default band remains 23–1024 Hz; calibration is fixed.

```sh
# Setup and finite likelihood check only:
.venv/bin/python examples/real_event/gw170817_pe.py
.venv/bin/python examples/real_event/gw170817_pe.py --likelihood hyperbolic --outdir results/gw170817_full_hyperbolic
# Launch a longer Gaussian run (assess convergence separately):
.venv/bin/python examples/real_event/gw170817_pe.py --sample --steps 1000 --burn 1000
```

Both likelihoods use identical science priors and cleaned strain. The
hyperbolic run adds one shared alpha and four frequency-segment delta
parameters. Full sampling has not been completed or validated for convergence.

1. Select the science priors and which parameters to sample; the larger driver
   already releases mass ratio, both spins, inclination, polarization, sky
   position, and `lambda_1`, `lambda_2`. Specify detector/source-frame masses,
   spin prior and cosmology consistently.
2. Match a particular published analysis: waveform, prior, strain release,
   frequency limits, PSD estimation and calibration treatment. GWTC-1 and the
   2018 dedicated BNS analyses do not all use identical products and settings.
3. Use several independent chains, autocorrelation/effective-sample diagnostics,
   mixing and stability checks. Benchmark waveform calls before committing
   to a full BNS run; validate any heterodyne acceleration against the full
   likelihood over posterior samples and the intended prior region.
4. Compare Gaussian cleaned-data PE against the corresponding public posterior
   samples. With identical waveforms and priors, run Gaussian and hyperbolic
   models on cleaned data and then on explicitly pinned uncleaned data.
   Check bias, coverage and residuals; robustness to this glitch is a hypothesis
   to test, not an assumed property of the likelihood.
5. Discovery significance needs an actual search, detector coincidence, data
   quality handling and background/time-slide analysis. The pilot only recovers
   a known signal in its known time and parameter region.
