# Saved classroom fast run

These are outputs from a previous **real-data**, Gaussian conditional fast run,
not a synthetic injection and not a new inference performed in preview mode.
The input files and their checksums, fixed parameters, band and setup are in
`manifest.json`. The data themselves are downloaded separately from GWOSC.

Settings: 32 s, 2048 Hz sampling, 64–512 Hz, TaylorF2; four sampled parameters,
10 burn-in and 20 production steps, 24 walkers, two temperatures, seed 170817.
The 480 cold-chain draws are correlated; convergence is not established.
The images and diagnostic quantiles are suitable for teaching the pipeline,
not for quoting astrophysical intervals from full GW170817 PE.
